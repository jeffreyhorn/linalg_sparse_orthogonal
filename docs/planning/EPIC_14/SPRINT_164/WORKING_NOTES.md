  installed-header-name changes;

- shared-library support;

- backend superiority;

- state-of-the-art coverage;

- performance proof from API-comment cleanup.

## Working Assumptions

- Day 1 is planning and inventory only; no public header is edited today.
- The selected cleanup batch will be chosen on Day 2 before any header edits.
- All selected header edits should be comment-only unless a later day records
  an explicit reviewed exception before editing.
- `docs/maintainer_guide.md` owns broad maintainer policy; headers keep only
  API-local caveats needed at call sites.
- `docs/api_reference.md` plus checked-in public headers remain the API truth.
- Generated Doxygen HTML remains ignored local output.
- Public-header edits require `make format && make lint && make test` plus
  declaration-preservation evidence.

## Stop Conditions

Stop and revise before proceeding if a change:

- changes a public declaration without an explicit reviewed exception;
- weakens declaration-preservation evidence;
- moves maintainer-only history or broad policy into public headers;
- implies ABI, shared-library, runtime-loader, package-manager, broad platform,
  backend-superiority, performance, or state-of-the-art proof;
- treats generated Doxygen HTML as hosted or source-controlled publication;
- cites Sprint 163 local benchmark/sentinel rows as API, package, ABI,
  platform, or performance proof;
- modifies `.c` or `.h` files without running the required quality gate;
- leaves generated `docs/api/html/`, `build/`, coverage, or cache output in the
  worktree for commit.
