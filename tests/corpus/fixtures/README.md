# Promoted Corpus Fixtures

This directory is reserved for future small, deterministic matrix fixtures that
are explicitly promoted into the maintained corpus.

Do not place optional external data, downloaded archives, generated outputs,
observed oracle rows, logs, or local report indexes here. Optional external
data belongs under `SPARSE_CORPUS_OPTIONAL_DATA_DIR`; generated outputs belong
under ignored `build/corpus/` or `build/corpus-reports/`.

The first Sprint 138 QR lane is generated and therefore does not require a
stored matrix fixture in this directory.
