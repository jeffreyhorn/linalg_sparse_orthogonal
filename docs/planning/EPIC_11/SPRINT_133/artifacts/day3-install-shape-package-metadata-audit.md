# Sprint 133 Day 3 - Install Shape and Package Metadata Audit

## Purpose

Day 3 audits Make install, CMake install/export, `pkg-config` metadata, static
library layout, version propagation, install validation, and package
documentation before Sprint 133 makes the shared-library versus static-first
product decision.

This is a documentation-only audit. It does not change Make install behavior,
CMake package generation, `pkg-config` metadata, install tests, public
headers, generated artifacts, or support wording.

## CMake Export Metadata Map

| CMake metadata | Current behavior | Static/shared interpretation |
| --- | --- | --- |
| Target definition | `add_library(sparse_lu_ortho STATIC ...)`. | Static target is explicit, independent of `BUILD_SHARED_LIBS`. |
| `BUILD_SHARED_LIBS` | Emits a status message that the package remains static-first and continues with `STATIC` library output. | Shared-library request is explicitly not a support contract. |
| Installed target | `install(TARGETS sparse_lu_ortho EXPORT SparseTargets ARCHIVE ... LIBRARY ...)`. | `ARCHIVE` is active for the current static target; `LIBRARY` destination is present but does not create shared support. |
| Export namespace | `Sparse::sparse_lu_ortho`. | Downstream CMake consumers link the maintained static target. |
| Include directories | Build interface includes generated and source headers; install interface uses `${CMAKE_INSTALL_INCLUDEDIR}`. | Installed consumers include headers as `<sparse/...>`. |
| CMake package config | Includes `SparseTargets.cmake` and `check_required_components(Sparse)`. | Minimal package entry point, no component or library-type negotiation. |
| CMake package version | Exact-version compatibility. | Prevents package-version metadata from implying broad ABI compatibility. |
| Optional OpenMP | Adds public compile definition `SPARSE_OPENMP` and links `OpenMP::OpenMP_C`; generated `sparse.pc` appends `${OpenMP_C_FLAGS}`. | Transitive static-link metadata exists, but shared runtime/loader policy remains unclaimed. |
| Optional mutex | Adds public compile definition `SPARSE_MUTEX` and links `Threads::Threads`; generated `sparse.pc` appends `-pthread`. | Transitive compile/link metadata exists for static consumers. |
| Math/dlopen links | Links `m` and platform dynamic-load libs publicly where needed. | CMake target captures transitive link dependencies for installed CMake consumers. |

## Static-Link Interface Assumptions

| Assumption | Current owner | Risk or follow-up |
| --- | --- | --- |
| Static library name is `libsparse_lu_ortho.a`; link flag is `-lsparse_lu_ortho`. | Make install, CMake static target, `sparse.pc`, install tests, docs. | Shared support would need explicit artifact naming and consumer selection rules. |
| Consumers include headers from `${prefix}/include/sparse`. | Make/CMake install, `sparse.pc`, CMake target include dirs, docs. | CMake and pkg-config paths agree today. |
| `VERSION` is package version source of truth. | Makefile, CMake, generated header, CMake config version, `sparse.pc`. | Still not an ABI epoch or compatibility policy. |
| Exact CMake package version is required. | `CMakeLists.txt`, `tests/test_cmake_install.sh`, maintainer guide. | Preserves static-first/non-ABI stance; shared support would need an ABI compatibility story. |
| Optional `SPARSE_OPENMP` and `SPARSE_MUTEX` alter public compile/link metadata. | CMake target and `sparse.pc` extra libs. | Package metadata does not currently encode build-mode identity beyond flags. |
| `SPARSE_IDX_BITS` and `sparse_scalar_t` are compile-time header contracts. | Public headers and downstream rebuild requirement. | Package metadata does not expose index width or scalar ABI identity. |
| `Libs.private` is absent from `sparse.pc`. | `sparse.pc.in`. | Static-only consumers get dependencies in `Libs`; future shared/static split may require private/public dependency policy. |

## Day 4 Handoff

Day 4 should audit downstream consumer expectations using this install-shape
baseline:

- Make and CMake install paths both currently prove static archive output and
  absence of shared artifacts;
- CMake consumers link `Sparse::sparse_lu_ortho`;
- pkg-config consumers receive `-I${includedir}`, `-L${libdir}`,
  `-lsparse_lu_ortho`, `-lm`, and optional build flags;
- version metadata is exact-version package metadata, not ABI compatibility;
- installed header proof is 19 headers in the current contract, but CMake test
  enforcement is weaker than the Make install proof;
- package metadata lacks static/shared selection, ABI identity, index-width,
  scalar-width, and package-manager claims.
