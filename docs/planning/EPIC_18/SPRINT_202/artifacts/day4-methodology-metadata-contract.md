# Sprint 202 Day 4: Methodology Metadata Contract

## Summary

Day 4 defines the methodology metadata contract for the selected Sprint 202
lane before workflow or validator implementation. The selected lane remains:

- platform: macOS hosted runner;
- row: `SRT-BENCH-REFACTOR-CSC-NOS4`;
- artifact: `build/bench-reports/canonical/bench_refactor_csc.csv`;
- interpretation: hosted selected threshold-free freshness evidence only.

## Platform Metadata Contract

The hosted macOS lane must emit non-empty platform-bound values for:

- `report_label`;
- `generated_at_utc`;
- `git_commit`;
- `git_branch`;
- `platform`;
- `compiler`;
- `runner_context`;
- `build_flags`;
- `cpu_model`;
- `build_mode`;
- `omp_num_threads`.

Hosted mode must not use `runner_context=local`, `build_flags=not_recorded`, or
`report_label=unlabeled`.

## Artifact Contract

The selected hosted upload set is exactly:

- `build/bench-reports/canonical/bench_refactor_csc.csv`;
- `build/bench-reports/canonical/index.tsv`;
- `build/bench-reports/canonical/manifest.txt`.

The selected CSV must contain exactly one `bench_refactor_csc` row for
`nos4.mtx`, `n=100`, and `scenario=chol_spd`. The LDLT dense backend fields
remain `n/a`.

Unselected canonical CSVs may be generated by the current script, but they
remain local-only threshold-free context and must not be uploaded as selected
hosted artifacts.

## Diagnostic Vocabulary

| Diagnostic | Meaning |
| --- | --- |
| Missing artifact | Selected CSV, `index.tsv`, or `manifest.txt` is absent. |
| Malformed metadata | Required columns, row width, non-empty fields, or timestamp shape are invalid. |
| Duplicate selected row | More than one selected `bench_refactor_csc` row exists. |
| Stale selected row | Selected row fields, selected CSV contents, or manifest fields no longer match the selected target contract. |
| Deferred artifact | Unselected canonical rows remain `local_only` / `local_threshold_free`. |
| Claim mismatch | Hosted selected rows are not `hosted_selected` / `hosted_selected_threshold_free`, or docs imply portable performance. |

## Documentation Contract

Public and maintainer documentation may eventually say that Linux and macOS have
reviewed hosted selected benchmark freshness for the selected
`bench_refactor_csc` row only. The docs must continue to exclude:

- portable performance;
- timing thresholds;
- benchmark superiority;
- broad benchmark-family publication;
- broad platform parity;
- Windows selected benchmark freshness;
- package-manager, ABI, runtime-loader, OpenMP speedup, backend superiority, or
  state-of-the-art claims.

## Day 5 Handoff

Day 5 should design the smallest validator, manifest, workflow, and fixture
changes needed to implement this contract. The design should preserve existing
Linux hosted behavior while adding macOS as the one additional hosted selected
benchmark freshness platform.
