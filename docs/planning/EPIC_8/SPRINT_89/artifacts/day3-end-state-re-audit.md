Reduce Sprint 89's broad final-integration problem to one ranked live

    product work
- strongest fourth target:

## Strongest Current Contradiction

The strongest current contradiction is now explicit:

- the project no longer lacks a sprint-by-sprint modernization story
- it no longer lacks strong internal reviewed, install/export, and bounded
  benchmark/reporting proof surfaces
- but it still does not yet have one final project-level end-state review plus
  bounded external comparison package strong enough to close Epic 8 from the
  same vocabulary that opened it

That makes the strongest first Sprint 89 move clear:

- do not jump straight to a speculative final fix batch
- first produce one explicit end-state review package
- then run one bounded external comparison sweep
- only after that decide whether any last-mile implementation work is still
  justified
