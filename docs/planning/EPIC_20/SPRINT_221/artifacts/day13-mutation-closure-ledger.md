# Day 13: Mutation Closure Ledger

The v1 mutation proof now includes 16 Day 12 syntax-valid CLI cases and five
additional cross-field CLI cases. Every case starts with a passing fixture,
asserts the exact rejection code and JSON pointer after mutation, and then
restores and revalidates the original. All generated bytes live under
`TemporaryDirectory`; no selected matrix, methodology file, corpus manifest
or canonical benchmark output is modified.

| Day 13 mutation | Expected code | Pointer | Gate reached |
| --- | --- | --- | --- |

| Hashed raw project solution changed while reported solution stays fixed | `status_contradiction` | `/correctness/project/raw_artifact/solution` | Raw/report binding after artifact hash |

| Publication approved with unlisted review path | `missing_provenance` | `/publication_review_artifact` | Review artifact linkage |

These close the remaining gaps in the CLI-level matrix: repository method
bytes, raw-output/report agreement despite a valid new digest, direct blocked
performance claims, ambiguous dependency identity and publication review
references. Day 12's [verdict matrix](day12-semantic-mutation-proof.md)
covers the selected matrix/hash, bundle bytes/path/hash, stale cell ID,
solver controls, one-sided results, raw timing samples, units, summaries and
unearned claims. Day 11 also exercises duplicate-key, unknown-field and
nonfinite parser/shape diagnostics. The earlier
`day9-fixture-closure-and-pilot-gate.md` maps all schema rule codes to
negative tests, including `implementation_pending` on a deliberately
weakened self-test schema. The current self-test passes; a pending result
is not an accepted evidence status.

Diagnostics are matched as `<code> <JSON pointer> record_id=...`. Tests do
not assert human-readable detail strings, which may change. Rehashed raw
bytes still cannot disagree with reported values; a valid SHA-256 is not a
substitute for semantic validation. Deliberately unsupported v1 shapes are
multiple cells, another matrix/RHS/solver/baseline selection, unverified
index ABI, one-sided success, missing paired timing samples and publication
without independent review. The validator does not authenticate the human
review's substance or prove that a synthetic fixture was generated by a real
CHOLMOD execution. Sprint 222 owns that first real two-sided cell.
