Current proof and package observations
--------------------------------------

- CMake library output is explicitly static-first through
  `add_library(sparse_lu_ortho STATIC ...)`.
- CMake prints an explicit status message when `BUILD_SHARED_LIBS=ON` is
  requested, preserving the static archive package contract.
- README and INSTALL both describe the maintained package surface as
  static-first rather than broad shared-library parity.
- Windows CI is a reviewed CMake-first consumer subset and currently expects
  51 registered CTest tests.
- Windows CI explicitly excludes `test_threads`, `test_sprint4_integration`,
  and `test_fuzz`.
- macOS CI enforces the Apple Clang reviewed path, includes a supplemental
  Homebrew GCC direct build/test leg, and has a supplemental Make
  install/pkg-config proof job.
- `tests/test_install.sh` validates Make install, installed headers, static
  archive, pkg-config output, and downstream pkg-config consumers.
- `tests/test_cmake_install.sh` validates CMake install, config/export files,
  `find_package(Sparse)`, example builds, and version compatibility.
